# Carbonix

وب‌سایت [carbonix.group](https://carbonix.group) — سیستم‌های کربوناسیون،
خنک‌سازی دو مرحله‌ای و سرو نوشیدنی گازدار.

سایت **کاملاً استاتیک** است: بدون build، بدون بک‌اند، بدون وابستگی. هر فایلی
که در این مخزن می‌بینید همان چیزی است که روی هاست می‌رود. برای اجرای محلی کافی
است یک وب‌سرور ساده روی ریشهٔ مخزن بالا بیاورید:

```bash
npx serve .
```

> فقط با `file://` باز نکنید — انیمیشن انتقال بین صفحات خودش را روی `file:`
> غیرفعال می‌کند و مسیرهای نسبی هم درست حل نمی‌شوند.

## ساختار

```
fa/  en/  ar/          سه درخت زبانی، هر کدام ۳۹ صفحه، ساختار آینه‌ای
index.html             انتخاب‌گر زبان (ریشه)
404.html               صفحهٔ خطا
check.html             صفحهٔ عیب‌یابی دیپلوی (noindex)
sitemap.xml            ۹۹ آدرس
robots.txt  .htaccess  _headers  _redirects
scripts/check-site.js  بررسی پیش از دیپلوی
assets/
  css/                 carbonix.css + fonts.css + google-fonts.css (تولیدشده)
  js/                  carbonix.js + vendor/ (GSAP، ScrollTrigger، Lenis)
  fonts/               ایران‌یکان + google/ — همه محلی
  img/  og/  brand/  files/
```

هر سه زبان دقیقاً یک مجموعه صفحه دارند: `about` · `applications` · `catalog` ·
`contact` · `faq` · `insights` · `privacy` · `products` · `projects` ·
`systems` · `technology` · `terms`.

`fa` و `ar` راست‌به‌چپ هستند (`dir="rtl"`)، `en` چپ‌به‌راست. مسیر `systems/`
از نسخهٔ قبلی باقی مانده و فقط شامل صفحه‌های `noindex` است که به `products/`
ریدایرکت می‌کنند.

## چند تصمیم که خودبه‌خود معلوم نیست

این‌ها را قبل از تغییر دادن بخوانید، وگرنه احتمالاً ناخواسته برشان می‌گردانید.

### هیچ چیزی از دامنهٔ خارجی بار نمی‌شود

GSAP و ScrollTrigger و Lenis داخل `assets/js/vendor/` هستند و پنج خانوادهٔ فونت
گوگل داخل `assets/fonts/google/`. دلیلش این نیست که «بهتر است» — دلیلش این است
که `fonts.googleapis.com` و `cdnjs.cloudflare.com` از داخل ایران قابل اتکا
نیستند و بازار اصلی سایت ایران است. ضمناً آدرس Lenis که قبلاً استفاده می‌شد
اصلاً روی cdnjs وجود نداشت و روی هر بار بارگذاری ۴۰۴ می‌داد.

### `robots.txt` نباید هرگز `/assets/js/` را ببندد

بخش‌های صفحه با `opacity: 0` شروع می‌شوند و فقط `carbonix.js` کلاس `rv-in` را
اضافه می‌کند. اگر خزندهٔ گوگل نتواند اسکریپت را بگیرد، کل محتوای سایت را
نامرئی رندر می‌کند.

### هدر و فوتر بیرون از `#page` هستند

ناوبری بین صفحات نرم است: فقط `#page` عوض می‌شود. یعنی هدر، منوی موبایل، فوتر
و دکمه‌های شناور از صفحهٔ اول باقی می‌مانند — در حالی که `href`های نسبی‌شان برای
عمق همان صفحه نوشته شده. `pinChromeLinks()` موقع boot آن‌ها را مطلق می‌کند.
بدون این، به‌محض اینکه عمق URL عوض شود همهٔ لینک‌های هدر ۴۰۴ می‌دهند.

### `.htaccess` و `_headers` / `_redirects` دو تلفظ یک کانفیگ‌اند

Apache و LiteSpeed اولی را می‌خوانند و بقیه را نادیده می‌گیرند؛ Cloudflare Pages
و Netlify برعکس. **هر تغییری در یکی باید در دیگری هم اعمال شود** — وگرنه بسته
به اینکه کجا دیپلوی کنید، ریدایرکت‌ها یا هدرهای امنیتی بی‌صدا از کار می‌افتند.

### سایت باید بدون جاوااسکریپت کار کند

سه قانون بالای `assets/js/carbonix.js` نوشته شده. اسکریپت فقط بهبود تدریجی
می‌دهد؛ اگر اجرا نشود صفحه باید همچنان خوانا و قابل ناوبری باشد.

## پیش از هر دیپلوی

```bash
node scripts/check-site.js
```

ده بررسی انجام می‌دهد و روی اولین خطا با کد غیرصفر خارج می‌شود:

| بررسی | چه چیزی را می‌گیرد |
|---|---|
| internal links resolve | لینک یا تصویری که به فایل موجود اشاره نمی‌کند |
| no third-party assets | برگشتن هر CDN یا فونت خارجی |
| ids unique per page | `id` تکراری (ماسک‌های SVG لوگو مستعدند) |
| robots.txt allows css/js | بسته‌شدن دوبارهٔ اسکریپت روی خزنده |
| every page has lang + dir | صفحهٔ RTL بدون `dir` |
| images have alt + width/height | نبود alt یا جابه‌جایی چیدمان هنگام بارگذاری |
| sitemap entries exist and are indexable | آدرس مرده یا `noindex` داخل sitemap |
| unlisted pages are noindex | صفحه‌ای که نه در sitemap است نه `noindex` |
| both host configs set a CSP | از هم دور افتادن دو فایل کانفیگ |
| forms carry the honeypot | فرمی بدون فیلد ضد‌اسپم |

هر کدام نمایندهٔ باگی است که یک‌بار واقعاً روی سایت رفته. اضافه‌کردن بررسی
جدید بعد از هر باگ، ارزان‌ترین کاری است که می‌شود کرد.

بعد از دیپلوی، `https://<domain>/check.html` را باز کنید — آن صفحه به هیچ
CSS و JS سایت وابسته نیست، پس حتی وقتی همه چیز خراب است هم رندر می‌شود و
می‌گوید کدام فایل نرسیده.

## فرم‌ها

فرم تماس و فرم درخواست کاتالوگ هیچ بک‌اندی ندارند. فرم تماس محتوا را به
`mailto:` تحویل می‌دهد و فرم کاتالوگ به واتساپ. یعنی:

- تا وقتی کاربر خودش در برنامهٔ ایمیلش دکمهٔ ارسال را نزند، **چیزی به دست شما
  نمی‌رسد** — پیام موفقیت هم دقیقاً همین را می‌گوید و ادعای «درخواست شما ثبت شد»
  نمی‌کند.
- روی دستگاهی که mail client تنظیم‌شده ندارد، این مسیر عملاً کار نمی‌کند.

اگر لید برایتان مهم است، یک endpoint واقعی (Formspree، Cloudflare Worker یا
هر چیز مشابه) روی `action` فرم بگذارید. ساختار فعلی جای این کار را باز گذاشته.

## لایسنس

کد و طراحی متعلق به Carbonix است.

فونت ایران‌یکان محصول تجاری [fontiran.com](https://fontiran.com) است و
استفاده از آن به لایسنس وب شما وابسته است. بقیهٔ فونت‌ها (Vazirmatn، Cairo،
Bricolage Grotesque، Inter، Fraunces) تحت SIL OFL 1.1 هستند. GSAP تحت
[لایسنس استاندارد GreenSock](https://gsap.com/licensing/) و Lenis تحت MIT.

جزئیات فونت‌ها در [`assets/fonts/README.md`](assets/fonts/README.md).
