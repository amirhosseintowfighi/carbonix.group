# Brand source art

The canonical Carbonix vectors. **Not deployed** — the pages inline the
logo as SVG rather than linking these files, so nothing on the site
references them and they would otherwise sit on the host unused.

| file | what it is |
|---|---|
| `carbonix-lockup.svg`   | mark + wordmark, the full lockup |
| `carbonix-mark.svg`     | the mark alone |
| `carbonix-wordmark.svg` | the wordmark alone |

If the logo in the pages ever needs changing, change it here first and then
re-inline it — otherwise the copies in the HTML become the only truth and
these drift out of date.

The deployed icons live one level up: `favicon.svg`, `favicon.ico`,
`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`.
