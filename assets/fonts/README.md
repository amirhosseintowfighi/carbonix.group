# فونت‌ها

هیچ فونتی از دامنهٔ خارجی بارگذاری نمی‌شود. همه چیز از همین origin سرو می‌شود.
دلیلش ساده است: `fonts.googleapis.com` از داخل ایران قابل اتکا نیست و بازار
اصلی سایت ایران است. قبلاً نسخهٔ انگلیسی و عربی برای بیشتر بازدیدکننده‌های
داخلی به فونت سیستمی سقوط می‌کرد.

## ایران‌یکان — فونت فارسی سایت ✅

سه وزن ایران‌یکان وب، هر کدام در دو قالب:

```
IRANYekanWeb-Regular.woff2 + .woff   →  وزن ۴۰۰  (و هر چیزی زیر ۴۵۰)
IRANYekanWeb-Medium.woff2  + .woff   →  وزن ۵۰۰  (و ۶۰۰)
IRANYekanWeb-Bold.woff2    + .woff   →  وزن ۷۰۰  (و ۸۰۰)
```

`woff2` اول می‌آید و `woff` به‌عنوان فالبک برای مرورگرهای قدیمی می‌ماند.
نسخه‌های woff2 حدود ۲۳٪ کوچک‌ترند (۳۵KB → ۲۷KB برای هر وزن).

هر `@font-face` یک **بازه‌ی وزن** اعلام می‌کند، نه یک عدد. یعنی اگر جایی از
CSS وزن ۶۰۰ خواسته شود، مرورگر فایل Medium را برمی‌دارد به‌جای اینکه Regular را
مصنوعی کلفت کند. به همین دلیل `font-synthesis: none` هم فعال است — بولد
مصنوعی روی فونت فارسی، اتصال حروف را خراب می‌کند.

> **لایسنس:** ایران‌یکان محصول تجاری فونت‌ایران است. فرض ما این است که شما
> لایسنس استفاده‌ی وب آن را دارید، چون فایل‌ها را خودتان فرستادید.

## بقیه‌ی فونت‌ها — پوشه‌ی `google/`

لاتین و عربی، همه SIL OFL و همه محلی. فایل‌ها از `fonts.gstatic.com` دانلود
شده‌اند و `assets/css/google-fonts.css` مستقیم به همین پوشه اشاره می‌کند.

| فونت | نقش | لایسنس |
|---|---|---|
| IRANYekanWeb | فارسی | تجاری (شما دارید) |
| Vazirmatn | فالبک فارسی | SIL OFL 1.1 |
| Cairo | عربی | SIL OFL 1.1 |
| Bricolage Grotesque | تیتر لاتین | SIL OFL 1.1 |
| Inter | بدنه لاتین | SIL OFL 1.1 |
| Fraunces | تأکید ایتالیک لاتین | SIL OFL 1.1 |

هر `@font-face` در `google-fonts.css` یک `unicode-range` دارد، پس مرورگر فقط
همان زیرمجموعه‌ای را دانلود می‌کند که واقعاً روی صفحه لازم است — کل پوشه ۶۹۰KB
است ولی یک بازدیدکنندهٔ فارسی‌زبان تقریباً هیچ‌کدام را نمی‌گیرد.

## اگر لیست فونت‌ها عوض شد

`assets/css/google-fonts.css` تولیدشده است، دستی ویرایشش نکنید. آدرس اصلی
Google Fonts که از رویش ساخته شده در هدر همان فایل نیست — اگر خانواده یا وزنی
اضافه شد، CSS را با یک User-Agent مدرن از `fonts.googleapis.com/css2?...`
بگیرید، فایل‌های `url()` را داخل `google/` دانلود کنید و مسیرها را به
`../fonts/google/…` بازنویسی کنید.

`node scripts/check-site.js` جلوی برگشتن هر ارجاع خارجی را می‌گیرد.
